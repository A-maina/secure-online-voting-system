# Secure Online Voting and Election Management System

## Overview

A secure web-based election management system developed using React, Flask, and MySQL.

---

## Technology Stack

### Frontend

- React
- Vite
- React Router
- Axios

### Backend

- Flask
- SQLAlchemy
- Flask JWT Extended
- Flask Bcrypt
- Flask Migrate

### Database

- MySQL

---

## User Roles

- Administrator
- Voter
- Independent Observer

---

## Features

- Secure Authentication
- Role-Based Access Control
- Election Management
- Candidate Management
- Secure Voting
- Audit Logging
- Election Results
- Reports
