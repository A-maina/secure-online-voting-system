# Secure Online Voting and Election Management System

## Overview

A secure web-based election management system developed as a Bachelor of Information Security and Forensics (BISF) project.

## Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- Flask
- SQLAlchemy
- Flask-JWT-Extended
- Flask-Bcrypt

### Database
- MySQL 9.7

## Features

- User Authentication
- Role-Based Access Control
- Election Management
- Candidate Management
- Secure Voting
- Audit Logging
- Election Results
- Reporting
